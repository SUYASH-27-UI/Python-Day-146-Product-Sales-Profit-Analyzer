# Python Day 146 - Product Sales & Profit Analyzer

## Description
A Python-based Sales Analyzer that reads product sales data from a CSV file and calculates revenue, profit, and product performance.

## Features
- Display product sales
- Calculate total revenue
- Calculate total profit
- Find best-selling product
- Search products
- Generate sales information

## Files
- `sales_analyzer.py` - Main Python program
- `sales.csv` - Product sales data

## How to Run
Keep both files in the same folder.

Run:

`python sales_analyzer.py`

## Concepts Used
- CSV File Handling
- Dictionaries
- Functions
- Loops
- Data Aggregation
- Revenue and Profit Calculations
